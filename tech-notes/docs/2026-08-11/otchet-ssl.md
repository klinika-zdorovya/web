# Отчёт заказчику: восстановление HTTPS-доступа сайта klinika-zdorovya.spb.ru

## Кратко

У сайта клиники истёк SSL-сертификат, из-за чего сайт перестал открываться
по HTTPS. Причина оказалась не в стоимости сертификата, а в незавершённой
проверке владения доменом при его продлении. Проблема устранена в тот же
день: сертификат выпущен и установлен, сайт снова полностью доступен по
HTTPS, проверка подтвердила корректную работу всех разделов.

## Ход работ

1. Обнаружена проблема — сайт перестал открываться по HTTPS (истёк
   установленный ранее сертификат).
2. Диагностика в панели хостинга (RU-CENTER): продление сертификата
   (GlobalSign SSL DV) уже было запущено, но зависло на этапе проверки
   права владения доменом.
3. Найдена причина: проверка домена — по электронной почте, письмо уходило
   на `admin@klinika-zdorovya.spb.ru`, который на практике не проверяется.
   По этой же причине не завершилась и прошлогодняя попытка продления —
   отсюда и истечение сертификата.
4. Способ проверки домена переключён на реально используемый почтовый
   ящик клиники, право владения подтверждено по ссылке из письма GlobalSign.
5. Сертификат выпущен и автоматически установлен хостингом (без ручной
   загрузки файлов).
6. Финальная техническая проверка — см. ниже.

## Результат проверки

- Сертификат: **GlobalSign GCC R46 DV TLS CA 2025**
- Домены в сертификате: `klinika-zdorovya.spb.ru`, `www.klinika-zdorovya.spb.ru`
- Действует: 11.08.2026 — 26.02.2027
- Протокол соединения: TLS 1.3
- Проверены разделы: главная, «О клинике», «Контакты», «Цены», «Врачи»,
  новости, публикации — все отвечают 200 OK
- Сайт открывается без предупреждений браузера (обычный и приватный режим)
- Смешанный контент (загрузка нешифрованных ресурсов на HTTPS-странице) —
  не обнаружен
- Формы, изображения, вложенные страницы работают штатно

## Рекомендации на будущее (не срочно)

1. Закрепить рабочую почту для проверки домена — убедиться, что адрес,
   использованный сейчас, кто-то регулярно проверяет, либо заранее сменить
   способ проверки в панели хостинга.
2. Поставить напоминание на январь 2027 — сертификат действует до
   26.02.2027, продление лучше начать заранее.
3. Настроить принудительный редирект с HTTP на HTTPS — сейчас обе версии
   открываются параллельно без перенаправления. Риска для посетителей нет,
   но правильнее централизовать на защищённой версии.
