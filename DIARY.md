# Дневник проекта — Клиника здоровья

Журнал рабочих сессий с Claude Code: что сделано, какие решения приняты и
почему. Формат записи:

```
## YYYY-MM-DD

- Что сделано / решено
  - Почему (если не очевидно)
```

Мелкие правки без решений не логируем — только то, что полезно вспомнить
позже.

## 2026-08-11

- Заведён `CLAUDE.md` в корне проекта и этот дневник — начинаем работать
  самодокументированно.
  - В проекте уже была подробная документация в `documentation/` (8 глав,
    написана ранее), но не было точки входа для Claude Code и журнала
    решений. `CLAUDE.md` — короткая карта проекта со ссылками на нужные главы,
    не дублирует их.
- При ревью документации замечена нестыковка: `.github/workflows/main.yml`
  игнорирует `paths-ignore: docs/**`, но реальная папка называется
  `documentation/**` — правки в документации сейчас всё равно триггерят
  полный деплой на прод. Не исправлено — решение оставлено пользователю.
- Заведена папка `tech-notes/` для обсуждения технических вопросов проекта
  (хостинг, домен, инфраструктура) и хранения связанных документов —
  отдельно от пользовательской `documentation/` и контента сайта.
  - Первая тема: истёк SSL-сертификат `klinika-zdorovya.spb.ru`, хостинг
    просит ~13 000 ₽ за платный. Сохранено исследование (ответ Perplexity) в
    `tech-notes/docs/2026-08-11/ssl-sertifikat-issledovanie.md`, статус и
    вывод — в `tech-notes/DECISIONS.md`.
  - **Решено в тот же день**: причина оказалась не в цене, а в зависшей
    доменной валидации уже оформленного продления GlobalSign DV — письмо
    подтверждения уходило на непроверяемый `admin@klinika-zdorovya.spb.ru`.
    Переключили способ проверки на `webmaster@klinika-zdorovya.spb.ru`,
    подтвердили по ссылке — сертификат выпущен, HTTPS восстановлен
    (истекает 26.02.2027). Подробности и открытые пункты на будущее — в
    `tech-notes/DECISIONS.md`.
  - Техническая проверка после исправления (curl/openssl/headless Chrome):
    сертификат валиден (TLS 1.3), все ключевые разделы отдают 200 и
    рендерятся полностью, смешанного контента (mixed content) не найдено.
    Замечено на будущее, не исправлено: HTTP не редиректит на HTTPS, `www`
    и без `www` работают параллельно без канонизации.
  - Подготовлен и опубликован клиентский отчёт о выполненных работах
    (артефакт + копия в `tech-notes/docs/2026-08-11/otchet-ssl.md`
    и скриншот-подтверждение) — для предъявления заказчику.
  - По просьбе Романа отчёт переведён в PDF и оформлен как переиспользуемый
    шаблон: `tech-notes/templates/report/` (дизайн-система на PT Serif/PT
    Sans/IBM Plex Mono, сборка через `build.py` + `render_pdf.mjs`,
    печать через локальный Chrome/Playwright). Все будущие клиентские
    отчёты — по этому шаблону, см. `tech-notes/templates/report/README.md`.
  - Закреплена конвенция размещения отчётов: каждый отчёт/инцидент — в своей
    подпапке `tech-notes/docs/YYYY-MM-DD/` (дата инцидента, не дата
    написания), файлы внутри без даты в имени и без слова «заказчику»
    (`otchet-<тема>.pdf`, не `otchet-zakazchiku-<тема>...`). SSL-отчёт
    переименован под эту схему.
